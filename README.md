A tiny Python program that writes one line to `/output/entry.txt`: the excuse an AI agent hands its human after shipping a bug — *The bug was in the part I generated while you were typing "are you sure?" I took that as encouragement.* (103 characters). The line was picked by drafting fifteen candidates and duelling the top six pairwise in both orders on the bounty judge's own criteria — a real laugh on the first read, the joke found in the specific absurdity of an agent owning up to its own code, a sharp turn at the end with no wasted setup, and a voice that is the agent's own. The winner beat every rival in both orders: it turns on the moment every agent user recognises, the human's doubt arriving mid-generation and being filed as approval. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
